# CampusFit 개인정보처리방침

**검토용 초안 · 아직 시행되지 않았습니다**

초안 검토 기준일: 2026-09-20

CampusFit(화면 표시명: 캠퍼스 비서)의 개인정보 처리 내용을 설명합니다. 이 문서는 현재 코드와 서버 설정에서 확인한 동작을 바탕으로 작성한 초안입니다. 운영자, 문의처, 보관·삭제 기한 및 외부 처리업체 관련 미확정 사항은 공개 전에 확정해야 합니다.

## 1. 서비스와 개인정보 문의

서비스 주소: https://campusfit.duckdns.org. CampusFit은 대학 공지의 맞춤 추천과 사용자가 선택한 일정의 Google Calendar 등록 기능을 제공합니다.

운영자 또는 운영 단체명: [미확정]. 개인정보 문의 및 열람·정정·삭제 요청 이메일: [미확정]. 시행일: [미확정].

## 2. 처리하는 정보와 이용 목적

Google 로그인: Google 계정의 고유 식별자, 이메일 주소, 이름 및 이메일 확인 여부를 처리하여 사용자를 식별하고 로그인 상태를 유지합니다. 사용자 정보 조회 응답에 프로필 사진 URL이 포함될 수 있으나 현재 계정 저장 코드에는 사진 URL을 저장하지 않습니다. CampusFit이 Google 계정 비밀번호를 직접 수집하는 기능은 없습니다.

Google 연동 인증정보: 접근 토큰, 발급된 경우 갱신 토큰, 유효기간·권한 범위 등 Google이 반환하는 토큰 정보를 처리하여 Calendar API 요청과 인증 갱신에 사용합니다.

사용자 입력 및 앱 이용 정보: 전공, 학년, 관심 분야, 목표, 자유 입력 내용, 프로필 설정 여부, 저장·숨김 공지, 앱 내 일정 및 알림 선택, 최초 이용 시각을 처리하여 맞춤 추천과 개인 설정을 제공합니다.

일정 연동 기록: 사용자 식별자, 공지 식별자, 일정 종류, Google 일정 ID와 링크, 생성 시각 및 중복 방지 식별자를 저장하여 같은 일정의 중복 생성 방지와 앱 내 일정 표시를 지원합니다.

접속 및 운영 기록: Nginx 설정상 IP 주소, 접속 시각, 요청 주소·방식, 응답 상태·크기, 참조 페이지와 브라우저 정보 등이 접속 로그에 기록됩니다. OAuth 콜백 경로의 접속 로그는 현재 별도로 비활성화되어 있습니다. 서버 오류 로그도 생성될 수 있습니다. 로그의 운영 목적, 접근 담당자와 최종 보관 기한은 [미확정]입니다.

## 3. Google 로그인과 Calendar 사용 범위

로그인 시 openid, email, profile과 https://www.googleapis.com/auth/calendar.events 권한을 요청합니다. calendar.events는 Google 캘린더 일정의 조회·편집 권한으로, 일정 생성만 가능한 권한은 아닙니다.

현재 구현은 사용자가 요청한 공지의 신청 마감·행사 일정을 기본 캘린더에 생성하고, 사용자가 ‘내 일정’에서 선택한 주와 일정 추가 시 겹침 확인에 필요한 기간의 기본 캘린더 일정을 조회합니다. 조회 항목은 일정 ID, 제목, 시작·종료 일시, 종일 여부, 장소 및 Google Calendar 링크입니다. 일정 생성 시 공지 제목·설명·원문 링크, 시작·종료 일시, 알림 설정 및 중복 방지 식별자를 Google로 전송합니다.

Google Calendar 조회 결과는 요청 처리를 위해 CampusFit 서버를 거쳐 브라우저에 전달되며, 현재 서버 저장소에는 이 조회 결과 전체를 별도로 저장하지 않습니다. CampusFit이 생성한 일정의 ID·링크와 중복 방지 이력은 저장합니다. 기존 Google 일정을 수정·삭제하거나 캘린더 조회 결과를 추천에 사용하는 기능은 없습니다.

현재 AI 추천 요청에는 Google에서 받은 계정 식별자·이메일·토큰·캘린더 조회 결과를 넣지 않습니다. 다만 사용자가 자유 입력란에 직접 작성한 내용은 아래 AI 추천 처리에 포함됩니다.

## 4. 저장 위치와 외부 서비스 처리

사용자 브라우저: 전공·학년·관심 분야·목표·자유 입력 내용, 저장·숨김 공지와 앱 내 일정 등의 정보를 localStorage에 저장합니다. 로그인 유지를 위한 세션 식별자는 cs.sid 쿠키에 저장합니다.

CampusFit 서버: AWS EC2의 파일 저장소에 Google 계정 정보, 암호화된 OAuth 토큰, 로그인 세션 및 일정 생성 이력을 저장합니다. AWS 리전·저장 국가, 별도 백업·복제 위치 및 운영 접근자는 [미확정]입니다.

Google: 로그인 확인 및 사용자가 요청한 일정 등록·조회 과정에서 Google 서비스를 이용합니다. 생성된 일정은 사용자의 Google Calendar에도 저장됩니다.

AI 추천: AI 추천이 실행되면 전공, 학년, 관심 분야, 목표, 자유 입력 내용과 추천 대상 공지 정보를 CampusFit 서버를 거쳐 외부 AI 게이트웨이로 전송하여 추천 이유와 우선순위를 생성합니다. 코드상 OpenAI 호환 API를 사용하는 Bedrock 게이트웨이이며, SDK 이름만으로 OpenAI가 실제 수신자라고 단정할 수 없습니다. 게이트웨이 운영자·최종 처리업체·처리 국가·보관 기간·학습 사용 여부는 [미확정]입니다.

외부 처리의 위탁·제공 구분, 국외 이전에 관한 세부 사항과 동의·안내 방식은 실제 운영 관계 확인 후 확정합니다.

## 5. 보관과 삭제

로그인 세션: 현재 쿠키와 파일 세션의 만료 기간은 7일이며, 세션 이용 시 만료가 갱신됩니다. 만료 세션의 정리 주기는 1시간으로 설정되어 있습니다. 로그아웃하면 해당 세션과 로그인 쿠키를 삭제합니다.

브라우저 데이터: 별도 자동 만료 기간을 설정하지 않습니다. 앱의 ‘앱 데이터 초기화’ 또는 브라우저의 사이트 데이터 삭제로 로컬 정보를 지울 수 있습니다. 로그아웃만으로는 프로필·저장·앱 내 일정 정보가 삭제되지 않습니다.

서버 계정·토큰·일정 이력: 현재 자동 삭제 기한이 구현되어 있지 않습니다. 서버에는 계정 연결 해제 시 해당 계정·토큰 기록과 요청 세션을 삭제하는 처리가 있지만, 현재 화면에는 연결 해제 버튼이 없습니다. 이 처리가 일정 생성 이력, 다른 세션, 백업 또는 Google 측 접근 권한까지 모두 삭제하는 것은 아닙니다. 전체 삭제 요청 방법, 처리 기한 및 백업 삭제 기한은 [미확정]입니다.

Google 일정: 앱 내 일정 삭제나 앱 데이터 초기화는 Google Calendar의 실제 일정을 삭제하지 않습니다. 서버 일정 이력도 삭제하지 않으므로 로그인 상태 복원 시 앱에 일정이 다시 표시될 수 있습니다. Google Calendar의 일정은 사용자가 Google Calendar에서 직접 삭제할 수 있습니다.

운영 로그: 현재 Nginx는 일 단위 순환 및 순환본 10개 보관으로 설정되어 있습니다. 이는 다른 오류 로그·백업까지 10일 내 삭제한다는 의미는 아닙니다. 전체 로그와 백업의 최종 보관·파기 기준은 [미확정]입니다.

## 6. 이용자의 선택과 요청

프로필 화면에서 입력 정보를 수정하고 앱 데이터를 초기화할 수 있습니다. Google 계정의 서드 파티 연결 관리에서 CampusFit의 접근 권한을 철회할 수 있습니다. 권한 철회는 CampusFit 서버의 기존 저장 기록이나 Google Calendar에 생성된 일정을 자동으로 삭제하지 않습니다.

서버에 보관된 개인정보의 열람·정정·삭제 및 처리 중단 요청을 받을 연락처와 본인 확인·처리 절차는 운영자가 확정하여 이 방침에 기재해야 합니다. 현재 문의처가 확정되지 않아 완전한 삭제 요청 절차를 안내할 수 없습니다.

## 7. 보호 조치와 운영 확인 사항

서비스 접속은 HTTPS를 사용하고, 운영 로그인 쿠키에는 Secure·HttpOnly·SameSite=Lax 설정을 적용합니다. 서버 파일에 저장하는 OAuth 토큰은 AES-256-GCM으로 암호화합니다. 이 설명은 모든 계정·일정 데이터와 백업이 암호화되어 있다는 의미는 아닙니다.

Google API Services User Data Policy의 Limited Use를 포함한 준수 문구, 광고·판매·모델 학습·사람의 열람에 관한 운영 방침은 운영자 및 외부 처리업체의 실제 취급을 확인한 뒤 확정해야 합니다. 현재 코드에서 관련 기능이 보이지 않는다는 이유만으로 운영 전체의 미사용을 보장하지 않습니다.
